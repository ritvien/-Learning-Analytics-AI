## Mục tiêu

Cải thiện **perceived performance** và **orientation** khi người dùng chờ dữ liệu:

1. **Skeleton loading** — khung placeholder mô phỏng bố cục thật (KPI cards, bảng, chart, filter bar…) thay vì màn hình trống hoặc một dòng chữ `Đang tải...`.
2. **Spinner có progress** — cho thao tác tải dài hoặc không có layout cố định rõ (submit, export, chuyển route nặng): hiển thị spinner kèm thanh progress (determinate khi biết %, indeterminate khi chưa biết).

Người dùng biết **nội dung sắp xuất hiện ở đâu** và cảm nhận hệ thống phản hồi nhanh hơn — đặc biệt quan trọng khi demo qua Ngrok/production cold start.

## Phạm vi

### A. Shared components *(tạo mới, tái sử dụng)*

| Component | Gợi ý path | Mô tả |
|:----------|:-----------|:------|
| `DashboardOverviewSkeleton` | `frontend/src/components/loading/` | Header + filter row + 4–5 KPI cards + 2 chart blocks + bảng |
| `AnalyticsTableSkeleton` | cùng thư mục | Filter bar + table header + N rows |
| `DetailPageSkeleton` | cùng thư mục | Breadcrumb/title + KPI strip + tabs/content |
| `CrudListSkeleton` | cùng thư mục | Toolbar + search + table pagination |
| `LoadingProgressOverlay` hoặc `PageLoadingProgress` | cùng thư mục | Spinner + `Progress` bar; props: `message`, `value?` (0–100), `indeterminate?` |

**Quy ước:**

- Skeleton **khớp spacing/grid** của page thật (cùng `gap`, card count, chiều cao chart tối thiểu).
- Copy loading tiếng Việt ngắn, nhất quán: `Đang tải dữ liệu...`, `Đang tải tổng quan...` (giữ message hiện có nếu phù hợp).
- Không block layout shift lớn khi data về — skeleton và content cùng wrapper width.

|:------|:----------|

| Dialog đã có skeleton (`course-analytics-dialog`) | Giữ nguyên; align style nếu cần |

### D. Spinner + progress

Dùng khi:

- Fetch không map được layout cố định (vd. export, generate report, submit form dài).
- **Route transition** hoặc cold start: optional top `LoadingProgress` (indeterminate) — chỉ nếu không trùng skeleton page-level.

Implementation gợi ý: `Progress` indeterminate mode (animate pulse width) hoặc `value` tăng dần theo số request hoàn thành trong multi-fetch page (optional P1).
