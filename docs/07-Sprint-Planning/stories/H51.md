## Goal

Bind the CTĐT corpus and pgvector retrieval from H62/H63 into the Universal Chat Agent so users can ask official curriculum questions about:

- ngành/chương trình đào tạo,
- mục tiêu đào tạo,
- CĐR/PLO,
- khối kiến thức,
- học phần,
- tín chỉ/cấu trúc CTĐT.

Every CTĐT answer must be grounded in retrieved chunks with citation file/trang/section. The tool must not answer personal grades, personal CLO, dropout risk, or generated ML probabilities.

## Runtime contract

Input:

- `query`: user question about CTĐT.
- `program_name`: optional program name/alias/code.
- `top_k`: clamped to 1..5.

Output:

- OK: JSON string with `status="ok"`, `query`, `program_name`, `program_name_inferred`, and `hits`.
- Each hit includes `content`, `score`, `citation_label`, `source_file`, `page_start`, `page_end`, `section_title`, `program_name`, `program_code`.
- Empty/unsupported/error: string beginning with `ERROR:` so the agent refuses softly and does not hallucinate.

Supported MVP programs:

- Công nghệ thông tin / CNTT / `7480201`
- Khoa học dữ liệu / KHDL / `7460108`
- Trí tuệ nhân tạo / TTNT / `7480107`

Non-MVP programs mentioned explicitly or inferred from the query return an unsupported-program error before retrieval.
