# H67 — Agent Concurrency Limiter & Backpressure

**Owner:** Hoàng
**Sprint:** 4 (post Demo Day nếu không kịp trước 05/07)
**Priority:** P2 (nâng P1 nếu demo nhiều người dùng đồng thời)
**Depends:** Không
**Effort:** 4–6 giờ tổng

## Goal

Tránh nghẽn server khi nhiều user chat đồng thời trên production (Render Free — 1 worker, 512 MB RAM). Hiện tại không có queue, rate limit, hay backpressure nào — mọi request chạy song song trong asyncio event loop, dễ gây OOM hoặc LLM API 429.

## Hiện trạng (trước H67)

- **1 uvicorn worker** (`backend/entrypoint.sh` dòng 24: `--workers "${WORKERS:-1}"`)
- **Không có** Kafka / RabbitMQ / Celery / Redis / Bull / FastAPI BackgroundTasks
- **Không có** rate limiting middleware
- Background duy nhất: `asyncio.create_task` cho report scheduler (polling 60s in-process)
- Mỗi agent run giữ LangGraph state + tool output trong RAM 5–30 giây
- LLM API key chia sẻ → nhiều concurrent run dễ trigger 429 từ provider

## Giải pháp chọn: In-process asyncio.Semaphore (Lớp 1)

Kafka / Redis queue không cần và không khả thi trên Render Free ($0). `asyncio.Semaphore` đủ cho single-instance, zero cost, zero dependency.

## Breakdown tasks

### H67a — ADR-0011: Concurrency strategy decision

- Viết `docs/decisions/0011-agent-concurrency-limiter.md`
- Ghi rõ: tại sao Semaphore thay vì external queue; constraint Render Free; khi nào nâng cấp
- **Effort:** 30 phút
- **Output:** ADR file committed

### H67b — Implement `_AGENT_SEMAPHORE` trong chat endpoint

- Thêm `asyncio.Semaphore(3)` (max 3 concurrent agent runs) vào `backend/app/api/v1/endpoints/chat.py`
- Áp dụng cho cả `POST /chat` và `POST /chat/stream`
- Khi hết slot: stream trả SSE error `{"type":"error","message":"Server đang bận..."}`, non-stream trả HTTP 429
- Cân nhắc config `MAX_CONCURRENT_AGENT_RUNS` qua env var (default 3)
- **Effort:** 1–2 giờ
- **Files:** `backend/app/api/v1/endpoints/chat.py`, `backend/app/config.py`

### H67c — Agent run timeout enforcement

- Wrap agent `ainvoke` / `astream_events` trong `asyncio.wait_for(coro, timeout=120)`
- Hiện chỉ Vercel proxy có `maxDuration=120`, backend không enforce
- Timeout → trả error + log event `agent_run_timeout`
- **Effort:** 1 giờ
- **Files:** `backend/app/api/v1/endpoints/chat.py`

### H67d — Frontend: hiển thị thông báo retry khi server busy

- Khi nhận SSE `{"type":"error","message":"...bận..."}` hoặc HTTP 429 → UI hiện thông báo thân thiện
- Nút "Thử lại" sau 5–10 giây, không auto-retry vô hạn
- Áp dụng cả `/chat` page và global chat widget
- **Effort:** 1 giờ
- **Files:** `frontend/src/app/(dashboard)/chat/page.tsx`, `frontend/src/components/layout/global-chat-shell.tsx`

### H67e — Test concurrent semaphore behavior

- Test: mock 5 concurrent requests, verify chỉ 3 chạy song song, 2 còn lại nhận 429/error
- Test: timeout enforcement khi agent chạy quá 120s
- **Effort:** 1 giờ
- **Files:** `backend/tests/test_chat_concurrency_h67.py`
