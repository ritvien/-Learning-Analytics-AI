### Scope

Trang **superadmin** quan sát hành vi user tổng quan:

- Danh sách browser **sessions** (`session_id`, user, thời gian)
- **Event log** — filter theo user, event_name, trace_id, khoảng thời gian
- **Trace drill-down** — nối page → chat → agent run → tool (theo `trace_id`)
- Metric tổng quan: số event, error rate, top routes/modules (từ API T53)

Chỉ role `superadmin` thấy nav/route; các role khác 403 hoặc ẩn menu.

### Do not touch

- `obs.event_log` schema / `log_event()` (T41/T53)
- Agent graph (Hoàng)
