# H64 — Memory / Cache Strategy for Universal Chat

**Owner:** Hoàng
**Sprint:** 4
**Priority:** P1
**Depends:** H48 (Universal Chat core)

## Goal

Triển khai memory/cache cho Universal Chat Agent:
- **Short-term**: session summary compaction (giữ context ngắn gọn cho LLM)
- **Long-term**: reuse `agent_memories` table cho user preferences & academic focus
- **Cache**: in-process CTĐT retrieval cache (embedding + search result)

Không thêm Redis/Mem0/Zep/Chroma — PostgreSQL-first + `cachetools` in-process.

## Memory Types

### Allowed (write vào `agent_memories` namespace `universal_chat`)

| Type | Ví dụ | TTL |
|:-----|:------|:----|
| `session_summary` | Tóm tắt cuộc hội thoại (lưu trên `chat_sessions.short_summary`) | Session lifetime |
| `recent_academic_focus` | Ngành/CTĐT/môn user đang quan tâm | 14 ngày |
| `user_preference` | Ngôn ngữ, phong cách trả lời | 90 ngày |
| `open_loop` | Câu hỏi cần quay lại (không chứa PII) | 7 ngày |

### Forbidden (KHÔNG BAO GIỜ lưu)

- Raw transcript / full message history
- Điểm cá nhân, GPA, số liệu cụ thể của sinh viên
- ML dropout probability / prediction
- Credential, API key, token
- System prompt hoặc prompt fragment
- Tool output chứa PII (email, SĐT, MSSV đi kèm tên)

## Cache Policy

### Query Embedding Cache
- **Key:** `(rag_embedding_model, normalized_query)`
- **Storage:** `cachetools.TTLCache`, maxsize=512, TTL=24h
- **Scope:** In-process only

### Retrieval Result Cache
- **Key:** `(corpus_version, program_name, normalized_query, top_k, rag_embedding_model)`
- **Storage:** `cachetools.TTLCache`, maxsize=512, TTL=24h
- **Scope:** In-process only

### Tool Result Cache
- Chỉ cho read-only analytics / public CTĐT
- KHÔNG cache dữ liệu cá nhân cross-scope
- Deferred — không triển khai trong H64

## Invalidation Strategy

- `corpus_version` = `f"{chunk_count}:{max_updated_at}"` từ `rag.ctdt_chunks`
- Khi re-index (thêm/sửa/xóa chunk) → corpus_version đổi → cache key mới → auto miss
- Đổi embedding model → cache key khác model name → auto miss
- Không cần manual cache clear

## Redis

Deferred sau Demo Day. In-process `cachetools.TTLCache` đủ cho single-instance deployment hiện tại.
