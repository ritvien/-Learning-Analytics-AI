### Scope

Chatbot classifies intent/complexity, orchestrates tools/retrieval beyond Report Center, returns `route_decision` schema (`mode`, `target_route`, `reason`, `preserve_context`). Shared session/memory; backend re-validates RBAC on every route decision.

### Implementation

| Component | Path |
|:----------|:-----|
| Route decision schema | `backend/app/agent/route_decision.py` |
| Context RBAC | `backend/app/agent/context_rbac.py` |
| Router node | `backend/app/agent/nodes.py` |
| Chat API response | `backend/app/api/v1/endpoints/chat.py` |
| Tests | `backend/tests/test_chat_agent_h48.py` |

### Do not touch

- Frontend chat shell / route handoff UI (V40 owner)
- RAG corpus preparation (T49 owner)
- DWH ETL internals (T42 owner) — consume APIs only
