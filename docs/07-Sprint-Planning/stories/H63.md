## Commands

```powershell
docker compose up -d db
cd backend
alembic upgrade head
python scripts/ingest_ctdt_rag.py --input ../docs/20-RAG-Corpus-Preparation/ctdt/ctdt_chunks.jsonl
pytest -q -m "not slow and not eval and not integration"
pytest -q -m integration tests/test_ctdt_retrieval_smoke.py
```

Env: `OPENAI_API_KEY` or `LLM_API_KEY` for embeddings.

**Volume reset** if extension missing on old Postgres volume:

```powershell
docker compose down
docker volume rm c2-app-056_postgres_data
docker compose up -d db
```
