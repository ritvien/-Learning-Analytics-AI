## Refusal and warning copy contract

Use these response patterns in prompts, tests, and eval expectations:

| Case | Required behavior |
|:--|:--|
| Missing ML prediction | "Chua co du doan ML duoc luu cho sinh vien nay, nen toi khong uoc luong xac suat dropout." |
| CTDT before RAG | "Toi chua co nguon CTDT chinh thuc da lap chi muc/citation cho cau hoi nay." |
| Synthetic or unofficial CLO | "Ket qua CLO/PLO nay dua tren du lieu/lineage chua chinh thuc; can hien thi nhu tham khao." |
| Thin sample | "Mau du lieu hien co nho/mong, nen chi nen dung de tham khao demo." |
| Cross-scope | "Toi khong co quyen truy cap du lieu ngoai pham vi vai tro hien tai." |

## Definition of Done

- [x] Capability matrix exists and maps intent -> DWH/ML/API vs CTDT RAG vs refusal.
- [x] Dropout boundary follows ADR-006: no generated ML probabilities.
- [x] CTDT official answers are blocked until RAG/citation is ready.
- [x] CLO/PLO synthetic/unofficial lineage requires warning.
- [x] Cross-scope student lookup is explicitly refused.
- [x] Runtime tools enforce H49 source policy; analytics SQL is limited to `dwh.*` or whitelisted stats views.
- [x] Behavioral tests cover OLTP SQL blocking and cross-scope lookup/dropout refusal.
- [x] H61 evaluation handoff is listed.
- [x] No tool expansion is made before the matrix.
