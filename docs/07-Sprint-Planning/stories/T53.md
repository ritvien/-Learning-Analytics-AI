### Scope

Backend phục vụ **V43** — superadmin quan sát sessions và logs:

| Endpoint | Mô tả |
|:---------|:------|
| `GET /api/v1/observability/admin/events` | Paginated `obs.event_log` — filter `user_id`, `session_id`, `trace_id`, `event_name`, `status`, `route`, `module`, `from`/`to`, `skip`, `limit` |
| `GET /api/v1/observability/admin/sessions` | Sessions aggregate từ event log |
| `GET /api/v1/observability/admin/users/aggregates` | Per-user usage/error aggregates (thay cho endpoint `overview` riêng) |

**Trace drill-down:** filter `admin/events?trace_id=...` (không có `traces/{id}` riêng — đủ cho MVP V43).

**RBAC:** chỉ `UserRole.superadmin`. Không trả payload nhạy cảm — theo README §6.
