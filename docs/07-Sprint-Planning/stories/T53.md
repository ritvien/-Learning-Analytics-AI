### Scope

Backend phục vụ **V43** — superadmin quan sát sessions và logs:

| Endpoint (gợi ý) | Mô tả |
|:-----------------|:------|
| `GET /api/v1/admin/observability/sessions` | List sessions — group by `session_id`, user, first/last event |
| `GET /api/v1/admin/observability/events` | Paginated `obs.event_log` — filter `user_id`, `event_name`, `trace_id`, `from`/`to` |
| `GET /api/v1/admin/observability/traces/{trace_id}` | Events cùng trace, sort `occurred_at` |
| `GET /api/v1/admin/observability/overview` | Aggregates — event counts, error rate, top routes (window 7d) |

**RBAC:** chỉ `UserRole.superadmin`. Không trả payload nhạy cảm (token, raw prompt) — theo README §6.
