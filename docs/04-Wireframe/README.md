# Wireframe Status

Các file PNG hiện tại là placeholder rỗng và chưa phản ánh kiến trúc DWH/ML mới.

Wireframe tiếp theo cần bổ sung:

- Trạng thái refresh DWH và thời điểm dữ liệu gần nhất.
- Prediction pass/trượt từng môn.
- Expected passed credits, expected failed credits và high-risk failed credits.
- Explanation, model version và prediction cutoff.
- Phân biệt descriptive analytics với predictive analytics.
